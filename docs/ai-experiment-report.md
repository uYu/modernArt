# AI 实现与对照实验（2026-09-18）

## 发布结果

启用 market-v3。它是“抽样出牌/补牌 + 稳健的局部竞价修正”，不是完整ISMCTS，也没有宣称算出了多人纳什均衡。旧版原样保留在 `src/game/ai-legacy.ts`；失败的完整模拟版保留在 `src/game/ai-search.ts`，其中出牌部分由正式版复用。

- 根据公开成交、结算事件记账，从已亮出的牌和自己手牌中排除未知牌。
- 出牌与补牌使用24个场景，评估季末排名、藏品组合、自购/出售结果；比较拒绝补牌与可用配牌，处理第五张和手牌耗尽不成交、卖家接任与后续出牌顺序。
- 最后一季若亮牌即可确定单独获胜，立即终季。
- 竞买保留旧版已知稳定的估值基线，公开竞价改为最小加价。卖家加价前比较放弃卖画收入的机会成本，并考虑公开推算出的竞争位置。
- 未通过跨对手验证的完整模拟竞价没有启用；暗标和一口价目前仍使用旧版规则。后续优化必须再次经过独立对照。
- 网页由Web Worker计算，暂停、打开菜单或离开对局会终止该次计算；异常或3秒超时回退旧策略并输出控制台警告。只向Worker发送Observation，没有发送完整状态或真实牌堆种子。
- 存档格式不变，历史动作仍由规则引擎重放。

## 实验设计

每场只有一个待测AI，其余座位是指定对手。遍历3/4/5人，每个牌种子轮换所有待测座位；先手为 seed % 人数。平局第一各计1/并列人数。

旧版对照使用相同牌种子、相同先手和相同座位，替换待测AI为旧版。纯旧版阵容的对照每seed只需运行一次，即可提取各座位结果；混合阵容则每个待测座位各运行一次旧版对照。

混合对手为旧策略派生的保守/激进变体：相对待测座位交替安排，报价及定价乘0.8/1.2并限制为合法预算；保守购买增加现金比例限制。它们不是人类策略，也不是全部可能对手，只用于检查简单行为分布变化造成的回退。

开发/消融seed使用1001段、40001段、41001段。正式版冻结后，最终测试改用未参与开发的60001–60060（旧版）和80001–80060（混合）。测试完成后没有根据这些结果调整策略参数。

共1,440局正式新版对战，以及900局实际运行的匹配旧版对照（纯旧版180局可复用各座位，混合720局）。下面的每组“局数”指新版对战数，不重复计入对照。

## 最终独立测试

差值区间按牌种子聚类，保留同seed全部座位的相关性，进行5,000次配对bootstrap。区间为逐项95%，未作多重比较校正。

| 对手 | 人数 | 局数 | 新版胜利分率 | 旧版对照 | 差值（百分点） | 差值95%区间 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 旧版 | 3 | 180 | 63.9% | 33.3% | +30.6 | +24.4 至 +36.7 |
| 旧版 | 4 | 240 | 41.0% | 25.0% | +16.0 | +10.4 至 +21.7 |
| 旧版 | 5 | 300 | 32.2% | 20.0% | +12.2 | +8.0 至 +16.3 |
| 保守/激进混合 | 3 | 180 | 38.6% | 35.6% | +3.1 | −5.0 至 +11.1 |
| 保守/激进混合 | 4 | 240 | 53.5% | 43.1% | +10.4 | +2.5 至 +18.3 |
| 保守/激进混合 | 5 | 300 | 26.7% | 20.0% | +6.7 | +0.3 至 +12.7 |

结论：对旧版提升明确；混合对手下4/5人有正向证据，3人的区间跨0，不能声称提升已被确认。六组点估计均未出现先前的大幅回退，因此采用v3作为本轮默认。不是“对任何对手都更强”的证明，也不是与熟练真人的强度评级。

## 失败结果与消融，不作隐藏

完整模拟v2（开发后用于筛选的旧测试集，不能当作v3最终测试）：

| 对手 | 3人 | 4人 | 5人 |
| --- | ---: | ---: | ---: |
| 旧版 | 71.7% | 45.8% | 38.2% |
| 混合 | 8.9%（对照46.7%） | 7.5%（对照47.5%） | 37.3%（对照22.3%） |

这种大幅跨对手回退说明报价模型不稳健；不能只拿对旧版的漂亮结果发布。

随后在混合集前10个seed做分模块消融：

| 替换部分 | 3人 | 4人 | 5人 |
| --- | ---: | ---: | ---: |
| 仅v2竞价，旧版出牌 | 1.7% | 8.8% | 18.0% |
| 仅v2出牌/补牌，旧版竞价 | 46.7% | 40.0% | 26.0% |
| 同场景旧版对照 | 50.0% | 40.0% | 16.0% |

这支持回退模拟竞价、保留出牌搜索的工程选择。消融只有120局/组，是定位证据，不是完整因果分解；v3两项竞价修正未再分别作单因素消融。

## 验证与运行代价

- 20项规则/隔离/回放测试通过，其中含90局全新版自对战、逐步卡牌资金守恒、四季终止和存档重放一致。
- 新增6项测试通过：公开账本、替换未知牌/隐藏余额/秘密报价后决策不变、确定获胜时终季、零预算合法性、卖家机会成本、最小加价与预算。
- TypeScript与Vite生产构建通过，包含独立Worker资源；相关改动通过Prettier检查。
- 最终测试记录约9.5万次AI决策。两组Node测量P95分别约2.17ms、2.24ms，最大约17.52ms。这是本机并行实验中的函数耗时，不包括Worker启动、消息传递、刻意设置的AI思考延迟，也不是移动端性能承诺。
- 网页验证使用独立5181端口新建的临时测试局，避免改变用户存档；检查生产Worker出牌、补牌、竞价及暂停/恢复，控制台无Worker错误或回退警告。

## 仍有的近似

季末预测不是整局规则树：后续对手选牌采用带噪声的启发式模型，远期双重拍卖接任不作完整展开；并未拟合真人行为。候选评价主要用现金/藏品相对财富代理，不是精确的终局获胜概率。前几季保留手牌只用轻量机会成本近似，尚无长期训练价值网络。

公开资金是从公开日志重建，没有读取对手余额字段。日志文本格式变化时需要同步更新账本解析并运行相应回归测试。AI有完美的公开记忆，但界面继续不显示艺术家实时数量或对手现金。

## 复现

```sh
npm test
npm run build
node --experimental-strip-types experiments/ai-benchmark.ts 60001 60 experiments/final-v3-legacy.json legacy full v3
node --experimental-strip-types experiments/ai-benchmark.ts 80001 60 experiments/final-v3-mixed.json mixed full v3
python3 experiments/summarize.py experiments/final-v3-legacy.json experiments/final-v3-mixed.json
```

失败版本与消融可通过最后一个参数v2复现：

```sh
node --experimental-strip-types experiments/ai-benchmark.ts 20001 60 /tmp/v2-legacy.json legacy full v2
node --experimental-strip-types experiments/ai-benchmark.ts 40001 30 /tmp/v2-mixed.json mixed full v2
node --experimental-strip-types experiments/ai-benchmark.ts 40001 10 /tmp/v2-bids.json mixed bid-only v2
node --experimental-strip-types experiments/ai-benchmark.ts 40001 10 /tmp/v2-offers.json mixed offer-only v2
```

原始逐局结果、现金、seed、座位和时间分布在experiments目录。正式结果包含AI版本及相关源码SHA-256；计时会随机器和负载变化，确定性动作及胜负不应改变。
