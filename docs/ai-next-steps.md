# AI 下一轮：先验证季末估值

2026-09-23 复查；随后实现了首轮第四季近终局实验。正式「专家」路由未变，尚未运行新胜率验收。

## 目前的结论

统一拍卖搜索曾相对前版专家取得明显提升，见 `universal-auction.md`。最近的公开行动加权实验只小幅改善手牌预测，整局胜利分率差为 -2.1 个百分点，95% 区间 [-8.8, +3.9]；尚无可靠提升，保持实验开关，见 `hand-belief-experiment.md`。

不能把这次结果解释为手牌预测没有价值，也不能用更多粒子或更复杂算法的名称保证提升。下一轮先检验现有决策器是否能利用这些信息。

## 代码确认的限制

1. `src/game/ai-universal.ts` 的 `searchAuction` 在采样循环之前调用 `estimate(o, artist)`，所有世界、所有候选共用这组画价。该估值没有接收采样出的对手手牌。
2. 模拟在 `while (state.auction)` 结束后停止，评分为现金与固定估值的藏品之和，再扣除领先对手的部分财富。它没有模拟后续出画、第五张终季或季末真实结算。因此手牌采样目前主要影响模拟的拍卖响应，尚未用于预测季末价值。
3. 模拟响应使用前版 `chooseImprovedAction` 加保守/激进缩放，整局实验对手却是当前 `chooseUniversalAction`。这是一项模型差异；不能在模拟中直接递归调用完整搜索来修补，否则计算量可能失控。
4. 预测指标主要衡量“是否持有某画家”，没有直接衡量持牌数量、终季能力和候选价格排序。小幅 Brier 改善不能代替决策收益。

这些是结构性限制，并未证明哪一项导致本次胜率结果。

## 下一轮的具体改法

已做独立实验版的统一季末评估器：`searchAuction(o, { evaluation: 'final-round' })`。候选动作仍由现有接口生成；在同一隐藏世界中完成拍卖后，继续通过真实规则和受观察限制的廉价策略出画、拍卖，直到本季结算，以各人真实结算现金评分。所有拍卖类型共用该评估器。

第一步只在第四季接近结束的局面跑实验。第四季结算可直接读取模拟现金，避免先引入跨季剩余手牌的另一个估值难题。模拟设 300 步保护；时间预算只在完成一整个配对世界后检查，因此可能超时。正式策略始终保持原基线。

模拟中的每名玩家只能接收自己的 `Observation`；根玩家不得据采样手牌直接替其他玩家选择动作。即便如此，这仍是依赖对手模型的 rollout，不应称为精确求解或完整 ISMCTS。

## 先做便宜的诊断，再做整局验收

`experiments/final-round-pilot.ts` 用专门开发种子生成第四季画家计数至少为 4 的拍卖局面，按 3/4/5 人各取相同数量。脚本保存逐候选评分、选择动作、完成场景数、耗时和关键源码哈希。默认使用宽松预算跑固定完整样本；可传入第五个参数设置决策时间预算。

固定候选集、隐藏世界和随机数，比较：

- A：现有拍卖结束后的静态估值。
- B：均匀采样 + 季末 rollout 估值。
- C：公开行动直接加权 + 同一季末 rollout 估值。

已加 `belief: 'weighted'` 实验模式：与均匀分支使用完全相同的提议世界，直接按公开行动似然计算加权平均和有效样本数，不重采样。正式均匀模式和以前的 `belief: 'played'` 重采样模式均保持原逻辑。先以固定完整样本数隔离估值变化，再以相同墙钟预算比较可用效果。

### 首轮开发局面结果

- 种子 810101，第四季近终局拍卖 12 个局面（3/4/5 人各 4），每模式固定完成 12 个场景：季末均匀评估相对原静态评估改变 **2/12** 次动作；同世界直接加权相对季末均匀评估改变 **1/12** 次。平均耗时分别约 **45 / 348 / 347ms**。逐局数据在 `experiments/final-round-pilot-expanded.json`。
- 同一批局面，最多 24 场景且 180ms 软预算：静态均匀平均完成 **24** 场景，季末均匀和季末加权分别完成约 **8.08 / 8.08** 场景；平均耗时约 **85 / 188 / 191ms**。季末均匀改变 **2/12** 次动作，直接加权再改变 **1/12** 次。软预算的完成数与动作可能随机器负载波动。逐局数据在 `experiments/final-round-pilot-budget.json`。
- 更早 6 局面、4 场景的探针显示，把旧专家用作整个季末模拟策略平均耗时约 2.7 秒；换成轻量后续策略约 62ms。两个探针的模型不同，不能作为胜率对照。原始记录保留在 `experiments/final-round-pilot-slow-policy.json` 与 `experiments/final-round-pilot-resampled.json`。

随后增加了离线行动质量诊断：只在评分时使用保存的真实隐藏状态；分别执行 A/B/C 选中的当前动作，当前拍卖余下部分用旧专家、之后用廉价观察策略推进到真实季末结算。该后续策略和终局评分对候选动作相同，真实隐藏手牌**绝不传入候选决策**。810101–810104 共 **48 个开发局面**，12 个固定场景/模式：B 相对 A 在此单次后续模拟中 **3 次更好、12 次更差、33 次打平**，平均效用差约 **-1.18**；C 相对 B 的结算效用在这 48 个局面均相同。后三组逐局数据在 `experiments/final-round-pilot-dev-810102.json` 等文件。第四季接近终局的相邻局面相关，真实状态只有一个，后续策略又是假设模型；这些数字不是胜率估计。但它们**不支持把此版季末模拟接入正式专家**。

固定样本结果只说明算法会改变动作。以 180ms 运行时，模式完成的世界数不同，不能把其评分差当严格配对价值估计。三个额外种子曾并行跑批，其耗时受资源争用影响；耗时参照单独运行的 810101 局面。

下一项应先针对变差的局面排查：集中在暗标、固定价和公开竞价，尤其 `810103` 的暗标出现大幅损失。检查抽样中对手报价与真实报价的差异、后续出画策略误差，以及每个候选的估值方差；增加可精确判定结果的终季战术局面来检查评分方向。再记录局面分层、完整 rollout 数、耗时分位数和候选排序与独立高预算参考的一致性。高预算参考同样依赖模型，只作诊断，不能称为真实最优。

可以增设“真实手牌替代采样”的离线上限诊断，检验现有模型对更准信息是否敏感；该分支必须与运行时决策隔离，不接正式 AI，也不能把其胜率报告为合法 AI 的效果。

如果 B 无法稳定改善局部判断，先检查对手响应模型、估值和截断偏差；如果 B 有益而 C 无益，先保留均匀采样。只有证明信息利用环节有效，再优先投入跨季粒子过滤和更复杂行为模型。

冻结候选后再写新的整局协议，使用未参与开发的新种子，覆盖全部人数/席位、当前专家及异质对手池，按种子聚类给出配对胜利分率区间，同时验证相同时间预算。达到可靠正向收益且耗时可接受后，才替换正式专家。

## 本轮交接

第四季近终局 rollout 实验开关、局面诊断脚本和 A/B/C 对照已完成。首轮离线真实状态续局指标偏负；下一项具体任务是排查失败局面和终季战术测试，再修正对手模型或采样效率。只有局部行动质量有正向证据，才扩大为整局胜率实验或全季评估器。
