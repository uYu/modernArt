# Modern Art AI 策略研究

研究日期：2026-09-18。本文是第一轮研究与实现方案，未修改游戏策略。后续的机制推导、60局旧AI诊断和对本方案的修正，见 [深入研究](ai-research-deep.md)。尚未进行新版胜率实验。

## 结论

优先采用“公开信息记忆 + 未知牌抽样 + 按拍卖规则模拟 + 候选动作收益比较”，建立可复现的对战基准后，再评估信息集蒙特卡洛树搜索（ISMCTS）。不应把固定折扣换成另一个所谓最优折扣，也不能把通用搜索论文当作本游戏的强度证明。

Modern Art 是带有共同结算价值、隐藏手牌、玩家间资金转移和多轮市场影响的多人游戏。普通单次独立私人价值拍卖的均衡公式不直接适用。玩家既竞买又做卖家，出画本身还会改变排名和本季结束时间。

## 当前代码的问题

检查对象：src/game/ai.ts、engine.ts、types.ts。

1. estimate 使用 count / 5 + own * 0.09 作为确定程度。这个数没有概率校准：某艺术家出了四张，不代表其他艺术家无法在季末挤掉它；自己有牌也不代表季末前有机会出。需要同时模拟五位艺术家和行动顺序。
2. 竞买预算不区分 seller 与 buyer。自己买自己的画要付银行，别人买自己的画会增加现金，两种结果必须放在同一收益比较中。
3. offerScore 在结束本季时使用整批藏品的结算收入，在普通出牌时使用单张估值和藏品增量。两个分支的绝对数值不可直接比较，可能形成不合理的提前结算偏好。
4. pair 只要有合法搭配就补画，不比较拒绝，也没有充分衡量补画触发季末、转移卖家身份或消耗下一季手牌的影响。
5. 暗标和一次出价使用固定比例，未建模剩余竞买者、座次及平价优先权。一口价未比较无人接盘时的强制自购结果。
6. 公开竞价按估值增加若干单位，未验证跳价是否比最小加价有利，可能无谓提高成交价。
7. Observation 没有公开事件记忆，无法利用过去成交和已亮出的旧牌；这会限制排除未知牌和估计对手行为。不能为此直接开放真实对手现金、手牌、牌堆或秘密报价。
8. personality 直接绑定玩家编号，暗标还有 player 的线性项，可能产生固定座位偏差。需把风格参数与座位解耦，并轮换座位测试。

这些是策略局限，不意味着规则引擎的成交和结算逻辑有误。

## 理论与适用边界

### 共同价值与赢家诅咒

同艺术家的画在同季有共同结算价格，但玩家持有的手牌影响他们对未来排名的判断。竞价胜出可能说明自己的判断偏乐观，因此应估计“在自己以该价格获胜的条件下”的收益，不能只用无条件平均画价。

这与共同价值拍卖的赢家诅咒有关，但本游戏价格会被后续行动改变，不能直接套用静态共同价值模型。依据：Yale ECON 159 第24讲、Milgrom 的拍卖理论综述。

### 外部性与相对收益

付款会帮助另一位玩家，谁赢得画也影响自己获胜的机会。这是竞拍外部性的具体表现。相关研究给出分析框架，而非本游戏的现成最优策略。

例：一幅画最终结算为60，自己付40给卖家，则自己本次净增20，卖家增40；本次交易使自己相对卖家的资金差减少20。这里没有计算不买时其他人拿画的替代结果，所以不能由此推出“最多出30”之类统一上限。

若自己是卖家，自购支付银行40可得到净增20；以40卖给别人则收到40，而买家净增20。选择哪种结果更有利还取决于双方领先情况与其他玩家。

### 信息集搜索

Cowling、Powley、Whitehouse（2012）的 ISMCTS 针对隐藏信息游戏，在信息集上共享搜索统计。它有研究支持，但没有提供 Modern Art 的最优性或胜率结论，也不保证在多人暗标博弈中收敛到纳什均衡。

仅抽一份对手手牌，然后用全知策略深搜，会产生“策略融合”：AI 仿佛能根据实际上看不到的牌选择后续动作。抽样并不等于允许作弊。根动作应跨样本统一评估，模拟中的每个玩家也只能使用该玩家自己的观察。暗标模拟中，后提交者不能读取前面已锁定的报价。

## 建议实现

### 1. 保存合法的公开记忆

增加结构化的公开事件：亮出的牌、最终成交额、卖家、赢家、公开出价、季末结算。不把内部状态或完整私密动作直接交给 AI。对现金只能根据可见历史推导；不能直接读取引擎中的隐藏余额。建立存档兼容与信息泄漏测试。

按已知牌池、自己手牌、各馆剩余手牌数和发牌轮次，抽样可能的隐藏牌分配。最初可均匀抽样，明确这只是基线先验；后续根据公开行为调整权重，避免把“对手没出某画”当成“对手一定没有”。

### 2. 统一动作评价

所有候选动作都推进到同一时间边界再比较，不能把一张画的收益与一整季的收入直接相加排序。

首版在样本中模拟到季末，评价季末资金、保留手牌的后续价值和对手相对位置。季末评分是近似目标；最终应以完整四季的胜率验证。末季可直接用最终胜负评分，平局按规则或统一分摊胜利分。领先时的保守、落后时的冒险最好由胜率目标自然产生，而非另加未经验证的性格倍率。

画价诊断可以写作：E[V_a] = sum(k=1..3) P(季末排名为k) × (历史累计奖励_a + 当季第k名奖励)。未进前三为0。该式不意味着一个静态画价足以决定动作：概率会随候选出牌、买家及后续策略变化。

### 3. 分别处理拍卖形式

| 形式 | 候选与模拟重点 |
| --- | --- |
| 公开竞价 | 比较暂不加价、最小合法加价及少量候选跳价；按游戏允许重新参与的规则模拟，不能把一次放弃当作永久退出。 |
| 一次出价 | 按剩余座次模拟后续报价；靠后行动者与靠前行动者的最优报价不相同。 |
| 秘密竞价 | 枚举或粗到细搜索整数报价，模拟对手报价联合分布、获胜条件和实际平价规则；各对手报价只能依赖各自信息。 |
| 一口价 | 卖家枚举可负担价格，模拟依次购买以及无人购买时的强制自购；买方比较购买与拒绝后的后续结果。 |
| 双重拍卖 | 联合评估首张、补牌和拒绝补牌，随后按第二张牌的拍卖形式模拟；准确处理第五张结束本季以及卖家身份变化。 |

以暗标为例，简化收益常写成 P(win at b) × (E[V | win at b] − b)。本游戏还必须加上未中标分支以及各玩家资金和藏品变化，因此实现中更适合直接对完整模拟结果求平均，而不是只优化这个简式。

### 4. 计算预算与工程

先做固定样本数的平坦蒙特卡洛候选比较，作为可解释、易复现的基线，再评估 ISMCTS 的收益。报价搜索避免从0枚举到全部现金的巨大分支，可先取关键价位，再细化最佳区间。

不同候选共享同一批随机场景，减少比较噪声。模拟随机源必须独立于真实牌堆种子。默认采用固定模拟次数保证回放一致；若用时间预算，则还需要记录最终动作或实际计算预算。

把搜索放到 Web Worker，避免界面卡顿。桌面单步约100–300毫秒可作为初始性能目标，不是已测结果；移动端需另测。超时或异常回退到合法的旧策略。

## 如何验证变强

- 固定旧 AI 为基线，加入随机合法、保守买画等不同对手，避免只针对一种策略优化。
- 分别测3、4、5人；同一批牌种子轮换新 AI 的座次；分别测一名新版对多名旧版，以及混合阵容。
- 参数调优与最终评估使用不同种子。起步使用每种人数200个牌种子并遍历所有座位，共2400局一新版对旧版对局，算力允许再扩大。
- 报告胜率、平均名次、现金差、决策耗时中位数及P95；平局规则固定。置信区间按牌种子分组计算，不能将同牌不同座次当作完全独立样本。
- 消融实验逐项关闭公开记忆、抽样估值、卖家分支和出牌搜索，验证改进来自哪里。
- 专项场景：第五张终止未成交、补牌终季、落出前三归零、卖家自购、一口价无人购买、暗标平价、预算耗尽、公开拍卖重新参与。
- 信息隔离：相同观察和相同AI随机种子，无论引擎中真实隐藏牌怎样变化都应产生同一决策；模拟对手也通过观察接口决策。

只有通过这些实验，才能宣称新版更强；规则自对战无报错不能替代策略评估。
