# 公开出牌驱动的手牌采样实验

2026-09-23 · `same-season-offer-belief-v1`。这是拍卖搜索的候选采样改进；是否接入正式「专家」由独立预测、整局胜率和耗时共同决定。

## 已实现的推断

规则引擎在出画、补画或公开放弃补画时记录结构化公开事件：行动者、牌（若亮出）、当时的画家数量和所有人公开的藏品。事件不包含对手手牌、牌堆、游戏种子或未揭晓暗标。记录来自真实行动转换，存档仍只保存原始行动并在重放时重建事件。

原采样器从未亮出的牌中无放回地均匀分配当前对手手牌。本实验先生成 48 个同样合法的完整场景，在每个场景里把**本季已公开打出的牌**加回对应玩家的候选当前手牌，按事件顺序逐张移除。由于本季内不补牌，这能重建该场景下玩家出画时可能持有的手牌。根据当时可选牌的局部评分计算其选中公开牌的概率，给场景加权；模型允许 20% 随机行为，也给“有牌却放弃补画”保留非零概率。权重收缩、保留均匀成分，再分层重采样 24 个场景供现有拍卖搜索使用。

这里只利用**本季**出牌行为：跨季会补牌，直接从当前手牌倒推更早的手牌会弄错；完整跨季粒子过滤留待后续研究。出牌模型是对手行为假设，不能从“不出某牌”推断其一定没有该牌。

代码：[公开事件与观察](../src/game/engine.ts)、[权重与采样](../src/game/ai-belief.ts)、[拍卖搜索开关](../src/game/ai-universal.ts)。当前正式专家仍使用均匀采样，候选版可通过 `searchAuction(o, { belief: 'played' })` 调用。

## 独立验证

冻结设计、开发与独立种子划分见 [验证协议](../experiments/belief-validation-plan.md)。预测评估只把真实隐藏手牌用于离线打分，采样器输入严格是玩家观察。主预测目标是“各对手当前是否持有某画家的牌”，每个局面和对手按五个画家计算 Brier 分数；越低越好。整局对照使用相同发牌、先手和待测席位，并列第一分摊胜利分。

独立预测集 720001–720012：3/4/5 人共 36 局，采集 **795 个局面、12,545 个“对手是否持有某画家”判断**。按全部判断加权，均匀采样 Brier 为 **0.14297**，行动加权为 **0.14178**；按种子聚类的配对平均差为 **-0.00120**，95% bootstrap 区间 **[-0.00225, -0.00033]**。这是小幅预测改善。对数损失的配对差为 -0.00371，区间 [-0.00947, +0.00213]，不能确认这项指标也改善。

独立胜率集 730001–730012：每局一名行动加权 AI，其余为当前正式专家；同发牌和先手运行全正式专家对照，轮换全部席位，共 **144 局候选对战**，并列胜者分摊胜利分。

| 人数 | 候选局数 | 行动加权胜利分率 | 均匀采样参考 |          差值 |
| ---- | -------: | ---------------: | -----------: | ------------: |
| 3    |       36 |            27.8% |        33.3% | -5.6 个百分点 |
| 4    |       48 |            29.2% |        25.0% | +4.2 个百分点 |
| 5    |       60 |            15.0% |        20.0% | -5.0 个百分点 |

三个人数等权的配对差为 **-2.1 个百分点**，按种子聚类的 95% bootstrap 区间为 **[-8.8, +3.9] 个百分点**。这不能证明提升，也不能以该样本确认显著下降。根据预先冻结的接入门槛，**正式「专家」继续使用均匀采样**；行动加权模式保留为实验开关。

同一观察位置交替测量两种模式，共 912 次拍卖决策：均匀采样平均 **58.47ms**、P95 **193.54ms**；行动加权平均 **61.13ms**、P95 **191.58ms**。最大分别为 308.10ms 与 311.01ms；180ms 只是场景之间检查的软预算。独立胜率集中的候选平均完成 22.3 个场景。两种模式的耗时差较小，但仍需考虑低性能设备。

原始数据、哈希和汇总：[预测数据](../experiments/belief-prediction-holdout.json)、[胜率逐局数据](../experiments/belief-win-holdout.json)、[同局面耗时](../experiments/belief-timing.json)、[统计汇总](../experiments/belief-holdout-summary.json)。胜率结果只针对当前专家自对手池，不外推熟练真人。

胜率 JSON 记录的是运行时源码哈希。跑完后对 `engine.ts`、`ai-belief.ts` 和 `ai-universal.ts` 做了 Prettier 排版；把运行前保存的三个文件以项目配置排版后与交付源码逐字节比较，结果一致。`types.ts` 只修正了观察类型的注释，其他记录的核心文件未改动。

这版的出牌选择模型虽然能利用部分公开信息，预测收益仍很小，整局搜索没有从中受益。下一步应先诊断哪些局面的手牌误差真正改变了报价/定价，再研究跨季补牌下的粒子更新和更贴近真实对手的出牌似然；仍需以新种子、异质对手和整局胜率验收，不以预测指标单独决定升级。

```sh
node --experimental-strip-types experiments/belief-prediction.ts 720001 12 /tmp/belief-prediction.json
node --experimental-strip-types experiments/belief-win-benchmark.ts 730001 12 /tmp/belief-win.json
node --experimental-strip-types experiments/belief-timing.ts
```
