# Expert v2 冻结验证协议

2026-09-20。开发种子 410001–410010，仅用于比较完整竞价改进、仅暗标、仅一口价三个版本。选择完整竞价版本后冻结 `expert-v2-auction`；以下种子未用于选择或调整参数。

- 主要对照 A：510001–510060，每局一个新版对其余旧专家；匹配对照为全旧专家。
- 主要对照 B：520001–520060，每局一个新版对其余保守/激进旧专家变体；每个座位单独运行旧专家匹配对照。
- 次要对照：530001–530030，对其余困难；匹配旧专家替换同一席位。
- 每组覆盖 3/4/5 人及所有待测座位；先手取 seed % 人数。每 seed 的所有座位作为一个相关簇。
- 主指标：每个人数组的平均胜利分差，再对三个人数组等权平均；并列第一分摊胜利分。两项主要对照各用 97.5% 双侧 seed-cluster bootstrap 区间，Bonferroni 控制两项主要比较的家族错误率不超过 5%。两个区间下界都大于 0 才称跨这两类对手的提升得到确认。
- 分人数区间为逐项 95%，仅作诊断；另输出 9 个子组 Bonferroni 校正区间。不得把跨零区间称为已确认单组提升。
- 至少完成 seeds×12 行结果才允许汇总；保留策略源码 SHA-256、全部现金、胜利分、种子与座位。所有失败版本保留。
- 运行中和完成后均不按这批结果调整参数。若修改策略，下一次必须登记新的未使用种子。
- 正确性门槛：规则资金流与局部模型对照、隐藏信息隔离、零资金合法性、全局回归和构建通过。
- 性能：同一机器串行重放采样的各机制决策，记录新旧策略耗时；新版须处于已有 250ms 单步预算内。旧专家保持原本计算量，不通过空等耗尽预算。

此协议不证明真人胜率，也不证明对所有未知策略都有优势。
